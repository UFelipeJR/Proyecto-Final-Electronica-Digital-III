### Nombre del Proyecto:

Pip-Boy

### Idea inicial:

El proyecto consiste en el desarrollo de un tipo de brazalete inteligente, inspirado en los smartwatches convencionales, pero en un formato mucho menos compacto. Como equipo se planteó implementar un sistema con pantalla TFT u OLED donde el usuario pueda interactuar por medio de un menú con todas las funcionalidades que se quieren implementar utilizando una perilla (tipo impresora 3D de entrada). Entre estas funcionalidades se incluye la lectura del ritmo cardíaco junto con el nivel de oxígeno en la sangre, un sensor de corriente y voltaje para estimar la corriente consumida por el sistema junto el voltaje de la fuente de alimentación, un GPS para obtener información acerca de la ubicación del usuario, una IMU para obtener información inercial, un sensor para obtener la respuesta galvánica de la piel y poder determinar si el portador se encuentra bajo estrés o algún otro estado, y finalmente un módulo RTC para guardar la hora. Adicional a esto se integrará un buzzer y un segundo actuador (con función por definir).


Respecto a la estética, para que el dispositivo no solo sea una caja con muchos componentes de entrada y salida, estará inspirada en los PIPBOY de la saga de videojuegos FALLOUT. Esta referencia consiste en un brazalete medianamente grande que permite alojar cómodamente todas las características y componentes que se pretende implementar, dándole una apariencia retro futurística y robusta al sistema.

### Motivación:

Al ser un equipo medianamente grande, todos teníamos ideas y gustos un tanto diferentes, por lo que se buscó una alternativa que pudiera integrar varias de ellas, por esto el desarrollo de este proyecto surge como una solución que integra algunas áreas como la biomédica, la gestión de energía y el desarrollo de interfaces gráficas. 

Dado que el diseño convencional de un smartwatch posee bastantes restricciones de espacio, se optó por el diseño de un brazalete robusto inspirado en la estética Pip-Boy (saga Fallout). Esta elección partió de nuestro gusto por los videojuegos, por lo que este diseño combina una identidad visual llamativa y adicional a esto resuelve el problema técnico del espacio para alojar toda la diversidad de sensores, actuadores e interfaz de usuario con la pantalla.
